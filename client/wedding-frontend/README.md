# Wedding Frontend

Frontend do site de casamento, mantido hoje como portfólio e memória do projeto original.

## Comandos

- `npm install`
- `npm run dev`
- `npm run build`

## Estrutura

- `src/data`: conteúdo do site e lista de presentes
- `src/components`: interface e seções da página
- `src/pages`: rotas do Astro

## Observações

- A lista de presentes é estática.
- Os links de pagamento ficam em `src/data/gifts.ts`.
- O foco atual é manter o site simples, rápido e fácil de atualizar.
